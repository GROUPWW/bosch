## 3. 解读（在各自最终测试集上直接成立）

- **h：扩充批次有害，最终测试集上直接可见**。起点即最终值（0.895 ≈ 0.903，半预算），47 条见顶（0.906）后随扩充批次降至 0.71–0.88 波动、末端 0.78——比 fixed8 版（0.67→0.58）更直接地证明"h 仅用原始批次校准"是正确的；同时"加样本不能推高 h"在最终口径下成立。
- **d：在其最终数据集规模处饱和**。42 条时 0.749，compat 扩充期间波动上升至 83 条的 0.775（≈最终值 0.792），83 之后（non-compat 段）不再提升（0.72–0.80 波动）——d 的获益恰好用尽在其最终数据集，之后饱和。
- **z/w 与 long 图相同**（fixed8 本来就不是搜索划分）：z 数据受益、w 高位平台后深槽退化。

## 5. 口径与注意事项

- 横轴 = 校准数据集总数（含固定留出；实际训练样本数 = 值 − 8（z/w，val=train）或 −12（h/d，8 test + 4 val））。
- 本图四面板测试集**不统一**（fixed8/ss184/ss177/fixed8），且 ss184/ss177 为搜索最优划分——因此只作 SI 互证，不替代主图；主图保留"预设未搜索、中位难度"的保守口径。
- h/d 用 best-val（val = 各自 manifest 的 4 条），与最终配置一致；z/w 用 val=train + last-epoch 规则。
- d 标签 >83 的点位超出了其最终数据集（含 non-compat 配方），图注需说明。
- 训练预算减半（1000ep），锚点与最终值的差（h 0.895 vs 0.903、d 0.775 vs 0.792）即预算差异量级。
- 三套独立协议（统一 fixed8 / 各自划分减样 / 各自划分增样）结论互洽：**h 饱和且扩充有害、d 受益至其数据集规模后饱和、w 高位平台后退化、z 持续受益**——过拟合回复的趋势主张不依赖任何单一评估协议。
