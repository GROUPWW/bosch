> 横轴口径（2026-08-18 起）：学习曲线横轴 = 校准数据集总数（含 8 条固定测试），实际训练样本数 = 该值 − 8。下表中的"42 条""104/109 条"等均为数据集总数口径，与主图一致。

## 一、数据核查结论

v20 学习曲线（半预算）与 v8/v8c 全预算独立实验（z 3000 / h 2000 / d 2000 / w 1000 epochs）在相同档位的对比：

| 面板 | 档位 | v20 曲线（半预算） | v8/v8c（全预算） | 结论 |
|------|------|------|------|------|
| z | 42 条 | 0.72±.02 | 0.69±.02 | ✓ 一致 |
| z | 104/109 条 | 0.86±.03 | 0.86±.02 | ✓ 一致 |
| h | 42 条 | 0.67±.00 | 0.68±.00 | ✓ 一致 |
| h | 82/85 条 | 0.61±.01 | 0.61±.01 | ✓ 一致 |
| d | 42 条 | 0.13±.03 | 0.10±.03 | ✓ 一致 |
| d | 104/109 条 | 0.35±.01 | 0.36±.01 | ✓ 一致 |
| w | 42 条 | 0.81±.01 | 0.81±.01 | ✓ 一致 |
| w | 67/69 条 | 0.82±.00 | 0.82±.00 | ✓ 一致 |

四点结论：

- **四面板数据全部准确**，预算减半不影响任何趋势判断；
- **d 的 0.35 不是 bug**：fixed8 对 d 是中位难度划分（200 组划分分布：中位 ≈0.39、P75=0.55、最优 0.78），0.35 正在中位附近；最终值 0.792 来自最优划分 ss177，差异纯属口径，已披露；
- **w 在 67 条截断正确**：全预算下 w 在 85 条掉到 0.58（深槽区间分布偏移）；
- **训练池干净**：池内不可用配方 5 条（B143/166/177/192/215）已全部剔除；B117/118/119 不在 109 分析池中，不影响曲线。
